# NASTRAN 支点反力パーサー（Excel VBA）

NASTRAN の支点反力テキストファイル（`.txt`）を Excel シートへ取り込む VBA マクロ群です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `Module1.bas` | パース・フィルタ・選択マクロ本体 |
| `CopyToOpenBook.bas` | 解析済みシートを別ブックへコピー |
| `import_vba.vbs` | VBA モジュールを xlsm へインポートする VBScript |

---

## セットアップ

### 前提条件

- Windows + Excel（マクロ有効ブック `.xlsm`）
- Excel の「VBAプロジェクト オブジェクト モデルへのアクセスを信頼する」を有効化  
  `ファイル → オプション → トラストセンター → トラストセンターの設定 → マクロの設定`

### 手順

**1. VBA のインポート**

```cmd
cscript import_vba.vbs C:\path\to\YourBook.xlsm
```

`Module1` が xlsm にインポートされ、保存・終了されます。

**2. UserForm の作成（1回だけ）**

Excel で xlsm を開き、VBA エディタまたはマクロ実行ダイアログから：

```
Module1.CreateUserForm
```

を実行します。`UserForm1`（節点番号選択フォーム）が xlsm 内に恒久作成されます。

---

## マクロ一覧

### `ParseSupportReaction`

テキストファイルを選択して全データを新規シートへ出力します。

- 出力シート名：`支点反力_YYYYMMDD_HHMMSS`
- 列構成：荷重番号 / 荷重名称 / 節点番号 / RX / RY / RZ / RMX / RMY / RMZ

### `ParseAndSelectNodes`

テキストファイルを解析し、節点番号選択フォームで選んだ節点のみ新規シートへ出力します。

- 事前に `CreateUserForm` の実行が必要です。

### `FilterByNode`

既存の解析済みシートから、指定した節点番号の行だけを抽出して新規シートへ出力します。

- 実行後に元シート名と節点番号（カンマ区切り）を InputBox で入力します。
- 例：`1,3,合計`

### `CopyToOpenBook`

解析済みシートを、現在開いている別ブックへコピーします。

- 別ブックが開かれていない場合はエラーになります。

### `CreateUserForm`（セットアップ用）

`UserForm1` を xlsm 内に作成します。セットアップ後に1回だけ実行してください。

---

## 入力テキストファイル形式

```
=================================================
荷重番号 =  100  荷重名称 = DL
=================================================
節点番号       RX          RY          RZ         RMX         RMY         RMZ
     101    1.000E+03   2.000E+03   3.000E+03   0.000E+00   0.000E+00   0.000E+00
     102   -5.000E+02   1.500E+03   2.500E+03   0.000E+00   0.000E+00   0.000E+00
合計          5.000E+02   3.500E+03   5.500E+03   0.000E+00   0.000E+00   0.000E+00
```
